# Frontend Angular — pendiente de inicialización

La carpeta está separada deliberadamente del backend y del recolector. No tiene `package.json` aún: no se simula una aplicación ya creada.

Cuando se autorice el Sprint 3, crear la aplicación con Angular CLI desde `apps/web` y mantener `--skip-git` para que no aparezca un subrepositorio. Elige versiones Angular/Node compatibles en ese momento.

Vistas previstas: login, dashboard, eventos, detalle de alertas, reglas y reportes. Nunca exponer la clave service-role al navegador; autenticación y RLS antes de leer eventos.
